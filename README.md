# NLG HM Set

Responsive monthly HM schedule builder for Tuesday / Thursday weekly planning.

## Features

- Thursday is the weekly anchor and Tuesday is calculated automatically.
- Works on desktop, iPhone and iPad.
- Add/edit/delete HM, Product and Set rows.
- Add special events.
- Copy the previous week's data or previous month's data.
- Auto-save in browser localStorage.
- Export the monthly schedule directly to PNG.
- On iPhone/iPad, PNG export uses the Share Sheet when supported.

## Usage

Open `index.html` in a normal browser or use the GitHub Pages site for the repository.

Data is stored locally in the browser being used. It is not synced between devices yet.
